MinUIPlus Installer

Put the latest MinUIPlus on the games card of your Powkiddy RGB20SX, from this page.

This browser can't write to a card. Open this page in Chrome, Edge, Brave or another Chromium browser on a computer (not a phone).

1 Plug in the games card

Take the card with your games and the .system folder (the one MinUI runs from) out of the RGB20SX and put it in your computer. This page is for a card that already has MinUI on it; it does not install Moss.

2 Choose the card

Press the button and pick the card's top folder. The browser will ask to let this page edit it; that is only used to copy the update.

3 Install

Downloads the newest release from GitHub, checks it, backs up each file it replaces, then copies it onto the card. Your games, saves and settings are not touched.


	


	

		
4 Eject and play

		
Eject the card from your computer before you pull it out, put it back in the RGB20SX, and turn it on. After this, Tools > Update on the device keeps it current over Wi-Fi.

		

	


	

		Something went wrong, or I want to go back
		
Every file it replaced was copied first to .system/rgb30/backup-before-fork-<date> on the card. To undo, copy those files back over the ones in the same place. Nothing on the other (Moss) card is touched.

		
Manual install: download the package from the latest release, unpack it, and run ./install.sh /path/to/the/card (Mac or Linux), or copy the files over by hand.

		
The source for this page and the release packages are at github.com/casualducko/MinUIPlus. Only the RGB20SX has been tested.
